-Poti sa concatenezi doua stringuri  prin "+"

-Poti sa verifici daca un substring exista intr-un string prin:

"world" in a - returneaza true daca substringu world exista in stringul a



Functii pe stringuri:
len(a) - returneaza cate caractere sunt in a

metode pe stringuri:

.replace(substring_replaceuit, substring_ia_locul) - daca exista substringul care se vrea replaceuit, o sa fie replaceuit cu substring 2
ex:
a = "hello world"
a.replace("hello", "see you")
a == "see you world"

a.upper() - returneaza tot stringul cu a caractere upper, dar nu il schimba si intern(in place).
